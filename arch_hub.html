Прототипы для архитекторов: этажность, солнечный свет с тенями (упрощённая модель), расчёт площадей/объёма материала, эскиз участка, подбор цветов. WebXR — если браузер и устройство поддерживают (часто нужен HTTPS).

Упрощённая геометрия: направление света считается по приближению для обучающей визуализации, не для нормативного расчёта освещённости.
